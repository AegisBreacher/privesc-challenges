# Simple privesc challenges

## Setup
Clone the repository
```git clone https://github.com/AegisBreacher/privesc-challenges.git```

Enter the directory of the challenge you want
```cd ./easy_sudo1```

Start the docker container
```docker compose up```

SSH into the box
```ssh aegis@localhost```

If it gives you key errors, follow the command your terminal gives you to allow ssh access
